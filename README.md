# TaskPair — исправленная первая версия

## Запуск

1. Распакуйте архив.
2. Откройте CMD в папке, где находится `app.py`.
3. Выполните:

python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py

4. Откройте http://127.0.0.1:5000

## Аккаунты

Постановщик:
giver / giver123

Исполнитель:
executor / executor123

## Важно

Не запускайте `app.py` двойным кликом. Сервер запускается командой `python app.py`, а сайт открывается в браузере.

В этой версии исправлена ошибка шаблонов: текущий пользователь автоматически передаётся во все страницы.

Правила:
- моментальные — без дневного лимита;
- обычные — максимум 1 на дату и только на будущую дату;
- долгосрочные — максимум 2 активных, обязательный дедлайн;
- сложные — отдельный тип без дополнительных ограничений;
- любое задание может требовать проверки;
- уведомления внутри приложения обновляются каждые 10 секунд;
- есть журнал активности.
